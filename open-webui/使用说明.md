# 在自己电脑上运行 Open WebUI（傻瓜教程）

Open WebUI 是一个开源 AI 聊天界面，界面好看，能把 ChatGPT / Claude 等模型整合成一个网页来用。

## 你需要准备

1. 一台 Windows 电脑（保持开机，运行时需要）
2. 安装 Docker Desktop：https://www.docker.com/products/docker-desktop/ ，一路下一步安装即可

## 启动步骤

1. 把本目录的 `docker-compose.yml` 下载到电脑上任意新建文件夹里
2. 在该文件夹的地址栏输入 `cmd` 回车，打开命令行
3. 输入并运行：`docker compose up -d`
4. 等待下载完成（第一次较慢），然后浏览器打开 http://localhost:3000
5. 注册一个管理员账号，登录即可

## 接入 AI 模型

Open WebUI 本身不带模型，需要在设置里填一个 API Key：

- 有 OpenAI API Key：设置 → 连接 → 填入即可开始聊天
- 想免费玩：可以再装 Ollama 跑本地模型（吃电脑配置，模型文件几个 GB，下载较慢）

## 关闭

在同一文件夹命令行运行：`docker compose down`

## 注意

- 电脑关机后服务就停了，开机后需要重新运行 `docker compose up -d`
- 这是给自己用的本地版本，不要把地址发给别人
